# StackMeet Developer Notes

## Public Results Portal

- Public portal files live under `backend/StackMeet.Api/wwwroot/results/`.
- `results.js` renders the public pages for Preliminary, Finals, All-Around, Doubles, Relay, and Medals.
- Preliminary qualifier labels use `settings.advanceIndividuals` from `PublicResultsController.cs`.
- Finals event cards intentionally show a `GAP` column instead of `Status`.
- When changing `results.js`, bump the query string in `backend/StackMeet.Api/wwwroot/results/index.html`.

## Time Sheet Printing

- Preliminary Individual, Doubles, and Timed Relay sheets are generated by `prelimTimeSheetHtml()` in `app.js`.
- Those sheets share the CSS class `.attempt-table`.
- Print-only column sizing is in `styles.css` inside `@media print`.
- Finals sheets are separate and use `.final-print-table`; do not change that when adjusting preliminary time sheets.
- When changing `styles.css`, bump the query string in both `index.html` and `backend/StackMeet.Api/wwwroot/index.html`.

## Deployment Caution

- For hosted fixes, deploy only the changed files where possible.
- Do not full-sync the publish folder unless you intend to replace server configuration.
- Avoid touching `web.config` unless the server settings are being deliberately changed.
