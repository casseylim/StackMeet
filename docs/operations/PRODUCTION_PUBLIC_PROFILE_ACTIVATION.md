# Governed Production Public Career Profile Activation\n\n## Purpose\n\nActivate exactly one reviewed competition stacker as a permanent NADITrack public career profile without ad-hoc SQL.\n\nThe tool is dry-run by default and reuses the reviewed identity matcher, SP-0C resolution policy, SP-1 persistence service, cryptographic NADITrack ID generator, and public career projection.\n\n## Safety boundaries\n\n- No database migration.\n- No raw SQL.\n- No competition Stacker mutation.\n- No automatic duplicate merge.\n- New identities are created private first by the existing persistence service.\n- Publication requires a second explicit --public gate.\n- Execute mode requires exact target-bound phrase: ACTIVATE PUBLIC PROFILE <competition-id>/<stacker-code>.\n- --expected-display-name must match the live row.\n- Existing identity candidates stop execution unless an operator explicitly supplies --existing-naditrack-id.\n- Dry-run emits PRODUCTION_WRITES=0.\n- Connection strings and private stacker fields are never printed.\n\n## Connection\n\nThe tool reads ConnectionStrings:StackMeet from the existing stackmeet-api-local-test user-secrets store, or STACKMEET_CONNECTION_STRING from the environment.\n\nNever paste a production connection string into chat, source control, command history, or evidence files.\n\n## Dry run\n\nRun the tool without --execute or --public using competition ID, stacker code, and exact expected display name.\n\nExpected markers: MODE=DRY-RUN, IDENTITY_CANDIDATE_COUNT, RESOLUTION_STATUS when eligible, DRY_RUN=PASS, PRODUCTION_WRITES=0.\n\n## Target review\n\nBefore public activation, confirm the selected row is an authorized synthetic/test participant or public-profile publication has been explicitly approved for the real participant. Do not infer consent from competition registration.\n\n## Execute\n\nAdd --operator-note, --public, --execute and exact --confirmation ACTIVATE PUBLIC PROFILE <competition-id>/<stacker-code>.\n\nIf an existing identity must be linked after operator review, additionally provide --existing-naditrack-id NDT-XXXXXXX.\n\n## Success evidence\n\n- IDENTITY_CREATED=True|False\n- IDENTITY_LINK_CREATED=TRUE|FALSE\n- PUBLIC_PROFILE_ACTIVATED=TRUE\n- PUBLIC_PROFILE_PROJECTION=PASS\n- PRODUCTION_WRITE=PASS\n\nAfter execution, verify /Stackers/<NadiTrackId> and the competition profile-links endpoint read-only.\n\n## Failure behavior\n\nAny target mismatch, incomplete snapshot, ambiguous identity candidate, invalid confirmation, or failed public projection stops the tool.\n\nIf identity persistence succeeds but publication verification later fails, do not rerun blindly. Inspect the existing-link state first in dry-run mode.
