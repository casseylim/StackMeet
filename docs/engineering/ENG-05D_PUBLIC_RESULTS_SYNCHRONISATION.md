## Source findings and implementation

- PublicResultsController accepts competition key/code, rejects collisions, archived/missing competitions and missing state with 404. Its HTTP direct-link contract differs from anonymous SignalR subscription, which also requires public listing. Do not change that authorization policy in this package. Unlisted is not necessarily withdrawn. The notification service may remove ineligible subscribers without delivering an event; the existing 15-second authoritative polling fallback remains essential.
- Replace the dropped in-flight trigger with single-flight refresh and retained pending intent. Both events, manual retry, initial/rejoin verification and periodic polling use the same coordinator. At most two passes per invocation; further pending work runs on the next event/poll rather than spinning. Each fetch uses no-store and a ten-second AbortController deadline.
- The timestamp in PublicResultsController is the max remaining row/state/asset timestamps, not a monotonic publication version. Deleting a row or changing official status may leave the timestamp unchanged or move it backwards. Keep timestamp/branding signature for compatibility and compare the complete returned projection as well. Identical successful reads avoid a redundant render; a changed projection always renders, including empty standings.
- Explicit fail-closed presentation: denied/missing/archived/withdrawn HTTP response, transient network/HTTP failure, timeout, malformed top-level payload or rendering failure invalidates the cached payload and signatures, hides all result sections (including medals), clears standings containers and stale branding/header, shows localized error state, and allows later authoritative polling/manual retry. Language switching cannot rerender the invalidated payload. This intentionally sacrifices scoreboard continuity during a temporary outage; no claim that previously viewed content is erased from browser history, external copies or caches.
- Rejoin before requesting a fresh HTTP projection; a join generation prevents an earlier read from marking the new subscription verified. Connected requires a successful read for the current joined generation. HTTP-only healthy fallback is Auto refresh; failure shows Reconnecting. A denied push join does not initiate a retry loop. A joined transport label does not guarantee ongoing server subscription authorization; public HTTP remains authoritative.
- EN/MS/zh-Hans unavailable-link messages and connection labels; updated public script/locale cache tokens. No API, auth privilege, schema, sports policy or deployment workflow changes.
